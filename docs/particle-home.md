## 实现

- `src/components/PointCloud.tsx`：WebGL 生命周期、静态后备图形与上下文恢复。
- `src/lib/particle-field.ts`：原生 WebGL、顶点／片元 Shader、交互与调度。
- `src/lib/xianova-mark.ts`：官方 Logo 的紧凑采样点数据，96×96 网格、1987 个有效位置，不依赖运行时图片像素读取。
- `src/components/sections/Hero.tsx`、`particle-hero.css`：首页版式、控制与中英文内容。
- 不新增 Three.js、外部翻译或远程渲染服务依赖。

每帧一次 `gl.drawArrays(POINTS)`。流光通过曲面着色计算，不增加节点绘制。每帧只更新时间、指针与形态权重等 uniform，位置变形交给 GPU。一个静态采样缓冲仅创建一次。

## 资源与降级

- 主体按绘图区每 CSS 像素 0.72 个候选点采样，容量根据设备面积初始化在 18 万至 80 万之间。桌面保持现有构图，手机按可用首屏面积确定数量。持续慢帧时降低数量，质量系数下限为初始数量的 36%；通过有限的光学密度补偿亮度，粒径不会随降级变大。动态绘制间隔至少 32 毫秒。

- 离开可视区域、标签页隐藏或手动暂停时停止 RAF 循环。
- 无 WebGL 时显示所选形态的静态 SVG，默认后备图同步使用新的偏心曲面参数；文字、导航与切换入口独立于 Canvas。
- 路由切换／卸载时删除 GPU 缓冲与程序、取消动画帧、断开观察器并移除监听器。

## 细粒径与独立曲面设计（2026-11-04，当前本地版本）
